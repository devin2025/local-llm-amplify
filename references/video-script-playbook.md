# 故事 / 情绪类视频脚本方法论

> 针对志怪、历史、叙事类短片。目标是"让人看完说不出的那一下"，
> 不是"把事情讲清楚"。

---

## 一、先分清两件事：故事 vs 情绪

| | 故事驱动 | 情绪驱动 |
|---|---|---|
| 核心 | 发生了什么 | 感受到了什么 |
| 结构 | 起承转合，有因果链 | 一个意象反复变奏 |
| 落点 | 反转或揭示 | 余味 |
| 风险 | 讲成了流水账 | 空转，全是情绪词没有实物 |
| 常见题材 | 志怪、案件、历史片段 | 亲情、离别、时代记忆 |

**大多数失败来自混淆**。想做情绪片却塞了一堆情节，
或者想讲故事却只堆形容词没有事件。

先定清楚你要哪一种。定错了后面全白做。

---

## 二、高概念：一句话说清"什么人被置于什么处境"

```
公式：[具体身份的人] + [反常处境] + [一个具体的时间/地点约束]
```

| 好 | 坏 |
|---|---|
| 一个在夜里替人写信的邮差，某天收到一封写给自己的信 | 关于书信的温情故事 |
| 敦煌藏经洞被发现后的第七天，第一个赶到的官员在算这批经卷值多少钱 | 敦煌的历史沧桑 |
| 一个给死人拍照的摄影师，最后一次按快门是对着自己的镜子 | 生与死的思考 |

判断标准：**能不能在 3 秒内让人听懂，并且产生"然后呢"**。
听不懂的、听完没有"然后呢"的，都不是高概念，是题材。

## 三、开场 3 秒：钩子的四种类型

短视频的生死线。这 3 秒决定了后面 57 秒有没有人看。

### 1. 反常

```
[画面] 一只手把信纸举到灯下。纸上只有落款，没有正文。
[旁白] 我替人写了十九年信。这是头一回，有人只要一个签名。
```

### 2. 具体数字

```
[画面] 昏暗的洞窟，手电扫过堆到顶的经卷。
[旁白] 五万卷。他用了七个数完。
```

数字比形容词有力一百倍。**"很多"没人记得，"五万卷"会被记住。**

### 3. 直接扔进场景（in medias res）

不交代背景，直接给一个正在发生的动作。

```
[画面] 他把最后一封信塞进邮袋，回头看见门口站着个没有影子的人。
[旁白] 那天是腊月二十九。
```

### 4. 第二人称

```
[画面] 镜头从桌面缓缓抬起，对着空椅子。
[旁白] 你最后一次收到手写的信，是哪一年。
```

### 反例：绝对不能用的开场

- "在历史的长河中……"
- "这是一个关于……的故事"
- "你知道吗，其实……"
- 任何形式的背景介绍

## 四、意象系统：一个物象，出现三次，含义三层

这是情绪类短片最核心的技术。没有意象系统的片子看完就忘。

### 结构

```
第 1 次出现：作为道具。中性的，不起眼。
第 2 次出现：带上情绪。观众开始注意到它。
第 3 次出现：含义翻转。同一个物件，完全不同的意思。
```

### 例子：以"灯"为意象

```
[开场] 他点亮桌上的煤油灯，开始写信。      ← 灯 = 工作
[中段] 灯芯爆了一下，他抬头，门口没人。      ← 灯 = 不安
[结尾] 灯灭了。信写完了。他没再点。          ← 灯 = 结束
```

同一个物件，不解释，靠位置和上下文改变含义。
**千万不要旁白点破**（"这盏灯就像他的命运"）——点破就死。

### 选意象的三条

1. **要具体可拍**。抽象的（"时间""命运"）不能当意象，要换成实物
2. **要能反复出现且不突兀**。选日常生活里本来就高频出现的东西
3. **要能有状态变化**。灯会灭、杯子会空、纸会黄——能变化才有叙事功能

## 五、情感弧线：60 秒怎么分配

```
0-3s    钩子       反常 / 数字 / 场景 / 第二人称
3-15s   建立       给出人物、处境、一个具体细节
15-35s  加压       意象第二次出现，出现第一个不对劲的信号
35-50s  转折       揭示或意象翻转
50-58s  落点       一个画面，不解释
58-60s  留白       黑场或定格，不要音乐收尾（或者音乐先停）
```

### 落点的处理

**结尾不要点题。** 一旦旁白说出"原来……""这就是……"，
观众刚要产生的情绪就被你替他说完了，反而没有情绪。

| 好 | 坏 |
|---|---|
| [画面] 他把信叠好，放进自己的邮袋。镜头不动，等三秒。 | [旁白] 原来那封信，是他写给自己的。人生最难的，是给自己一个交代。 |

好的结尾是**一个画面 + 沉默**。让观众自己完成最后一步。

### 煽情过度的红线

出现这些基本就废了：
- 泪水 / 哽咽 / 湿了眼眶
- 音乐突然煽情上扬
- "那一刻他终于明白"
- 慢镜头 + 大提琴

**情绪是克制的副产品，不是加码的结果。**

## 六、旁白声口

### 硬规则

1. **短句为主**。超过 20 字就拆。
2. **默读测试**。写完念一遍，拗口的全部改掉。
3. **抽象换实物**。这是最重要的一条。

| 抽象（删） | 具体（改） |
|---|---|
| 他很孤独 | 他每天买两份报纸，一份看，一份垫桌脚 |
| 时间过得很快 | 门口的春联褪成了粉的 |
| 她很难过 | 她把纸杯捏成了一个月牙 |
| 那时候很穷 | 一双鞋兄弟俩轮着穿，谁上学谁穿 |

4. **句式长短交替**。全是短句会像电报，全是长句念不出来。
5. **年代感靠用词，不靠成语**。写民国就用民国的物件名，不要"岁月沧桑"。

### 人称选择

| 人称 | 效果 | 适用 |
|---|---|---|
| 第一人称"我" | 亲密、可信、适合亲历者视角 | 志怪、回忆、职业叙事 |
| 第三人称 | 客观、有距离感、适合历史 | 历史叙事 |
| 第二人称"你" | 直接击中、适合开场钩子 | 只用一两句，全程用会腻 |

## 七、反 AI 腔清单

生成完必须逐条过一遍：

| 症状 | 例子 | 改法 |
|---|---|---|
| 排比堆砌 | 连续三个"有的……有的……有的……" | 砍到只剩一个，换成具体细节 |
| 否定排比 | "不是A，而是B" | 直接说 B |
| 空洞抒情 | 岁月、沧桑、令人唏嘘、时光荏苒 | 换成一个具体物件 |
| 破折号滥用 | 一inition句里两个以上破折号 | 拆成两句 |
| 三段式 | 任何地方出现三个并列项 | 砍成两个或改成递进 |
| 点题升华 | "原来，这就是……" | 删掉，留白 |
| 形容词加码 | 非常、无比、深深地、难以言喻 | 删掉形容词，加一个动作 |
| 万能开头 | "在……的历史长河中" | 直接进场景 |

自动化检测：用 `pipeline.py --mode script`，批判阶段的提示词里
已经内置了这份清单。

## 八、分镜格式

```
[画面] 具体可见的东西。谁、在什么光线下、做了什么动作、画面里有什么物件。
       不要写心理活动（"他若有所思"拍不出来）。
       写明：景别（特写/中景/全景）、光线、时间感。

[旁白] 能念出来顺口的短句。

[音效] 可选。只写具体的声音，不要写"悲伤的音乐"。
```

### 完整示例

```
[画面] 特写。一只手把信纸举到煤油灯前。纸上只有落款，没有正文。
[音效] 纸张翻动的沙沙声。
[旁白] 我替人写了十九年信。头一回，有人只要一个签名。

[画面] 中景。他放下纸，抬头。门口没人，但煤油灯的火苗歪了一下。
[旁白] 那天是腊月二十九。我记这么清，是因为再没过过别的年。

[画面] 特写。他把那张纸叠好，放进自己的邮袋——那里面全是别人写给别人的话。
[旁白] 十九年，我替人说过的话，比自己说的多。

[画面] 全景。他背上邮袋出门。雪地上只有一行脚印。
[音效] 门轴。风。
[旁白] 打那以后，我还是替人写信。只是每封的落款，我都多留一个位置。

[画面] 灯灭。黑场三秒。
```

## 九、志怪 / 历史题材的特殊处理

### 志怪

- **怪要藏在细节里，不要放在明面上**。写"门口站着个没有影子的人"
  比写"他看见鬼了"有力一百倍。
- **给怪一个规矩**。志怪的力量来自"有规则的反常"，
  不是随机惊吓。规矩越具体越可信（"子时之后不能回头"）。
- **不要解释怪的来历**。解释完就不可怕了。

### 历史

- **落到一个具体的人的一个具体的时刻**。不要写"这个时代"。
- **用细节建立年代**：物件名、货币单位、称呼方式。
  一个准确的细节顶一百句氛围描写。
- **避开宏大总结句**。"这是中华文明的瑰宝"这种一句话毁全片。

### 与 `zhiguai-director` skill 的分工

如果你要做的完整流程是「志怪/历史 AIGC 短片」（选题考据 → 高概念 →
念白剧本 → 分镜 → 配音配乐 → 生成提示词 → 发布），
**优先加载 `zhiguai-director`**，它是那件事的完整方法论。

本 skill 负责的是另一层：**让跑这整套流程的那个本地模型本身发挥得更好**。
两者叠加使用：

```
zhiguai-director  → 提供创作方法论和流程
local-llm-amplify → 提供参数档位、推理流水线、投票与验证工具
```

具体做法：用 `zhiguai-director` 的剧本骨架作为 `pipeline.py --mode script`
的输入，批判阶段的提示词用它的编审标准。

## 十、参数档位

脚本生成用 `video_script_story`：

```
temperature        0.92
top_p              0.93
top_k              50
min_p              0.05
repeat_penalty     1.12
presence_penalty   0.40
frequency_penalty  0.30
```

**这是四个场景里最激进的一套**。叙事文本对重复最敏感——
一个比喻出现两次，整段就废了。宁可牺牲一点连贯性换意象密度。

配套后端参数（llama.cpp）：

```bash
--dry-multiplier 0.8 --dry-base 1.75 --dry-allowed-length 2 --dry-penalty-last-n 1024
```

DRY sampler 对长文重复的抑制比 penalty 参数更有效，两者叠加用。

## 十一、推荐工作流

```bash
# 1. 完整流水线：规划 → 求解 → 编审 → 修订
python pipeline.py --mode script \
    --task "志怪短片：一个在夜里替人写信的邮差，某天收到一封写给自己的信" \
    --rounds 2 --out-dir out/script_01

# 2. 想要多个方向时：高温采样 3 个候选，人工挑
python llm.py --user "..." --profile video_script_story --n 3 --seed 100

# 3. 量化对比参数（比如测 temperature 对"意象密度"的影响）
python bench.py --taskset tasksets/video_script.json \
    --profile video_script_story --sweep temperature=0.8,0.92,1.0 --repeats 2
```

**注意：脚本类任务不要用投票。** 投票会把最平庸、最常见的那个方案选出来——
恰恰是你要避免的。多采样几个候选，人工挑，或者用 `--rounds 2` 的批判-修订。

## 十二、交付前自检

- [ ] 前 3 秒有没有钩子（不是背景介绍）？
- [ ] 有没有一个能被记住的核心画面？
- [ ] 有没有意象系统（一个物象出现三次，含义变化）？
- [ ] 旁白念出来顺不顺？
- [ ] 抽象情绪有没有全部换成具体物象？
- [ ] 结尾有没有留白（不是点题升华）？
- [ ] 反 AI 腔清单八条过了吗？
- [ ] 煽情红线碰了吗（泪水/哽咽/大提琴）？
- [ ] 总字数在限制内吗？
